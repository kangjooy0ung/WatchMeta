# WatchMeta

오버워치 유저를 위한 전적 분석 및 실시간 영웅 메타(티어표) 제공 모바일 웹 서비스

## 📄 프로젝트 기획서

| 항목 | 내용 |
| --- | --- |
| **1. 한 줄 정의** | 오버워치 유저를 위한 내 전적 분석 및 실시간 영웅 메타(티어표)를 제공하는 모바일 웹 서비스 |
| **2. 문제** | 인게임에서는 영웅별 세부 스탯 변화나 현재 시즌의 1티어 영웅을 한눈에 파악하기 힘듦. 매번 패치 노트를 찾거나 커뮤니티를 뒤져봐야 함. |
| **3. 해결책** | 유저 전적을 수치화해 보여주고, 최신 패치 내용과 픽률/승률 통계를 기반으로 역할군(탱/딜/힐)별 영웅 티어표를 직관적인 UI로 제공함. |
| **4. 왜 지금** | 오버워치는 잦은 패치로 메타가 빠르게 변함. LLM과 데이터 크롤링을 활용하면 방대한 패치 노트와 통계를 빠르게 분석해 티어표 갱신을 자동화하기 용이함. |
| **5. 사용자** | 오버워치를 즐겨 플레이하며 경쟁전 티어 상승에 관심이 많은 유저들. |
| **6. 대안·경쟁** | Overbuff 같은 웹 기반 전적 검색 사이트. / 차별점: 설치 없이 웹으로 바로 접속 가능하면서도 모바일 앱 수준의 깔끔한 UI, 그리고 '메타 티어표'를 전면에 내세운 픽 선택 가이드. |
| **7. 제품** | ① 유저 전적 검색 및 승률 시각화 ② 역할군별 영웅 티어표 ③ 패치 노트 요약 / MVP: ① 전적 검색 및 기본 스탯 뷰 ② 영웅 티어표 화면 |
| **8. 지속 방법** | 기본 기능은 무료로 제공하여 유저를 확보하고, 구글 애드센스와 같은 웹 배너 광고를 통해 유지보수 비용 및 수익 창출. |
| **9. 나(팀)** | 이전 프로젝트들을 진행하며 모바일 UI를 웹과 앱 양쪽으로 구현해본 경험이 있고, API 연동 경험도 있음. 평소 여가 시간에는 오버워치를 즐겨 플레이하며 유저들의 니즈를 잘 파악하고 있음. |
| **10. 6주 계획** | 3주: 오버워치 API 리서치 및 화면 흐름 기획 / 4주: 전적 검색 및 시각화 뷰 구현 / 5주: 영웅 티어표 화면 및 데이터 연동 / 6주: QA 테스트 및 Vercel을 통한 최종 MVP 배포 |
